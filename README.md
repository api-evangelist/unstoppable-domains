# Unstoppable Domains

Web3 domain name service providing REST APIs for resolving crypto domain names, managing NFT domains, reverse lookups, cross-chain address resolution, domain registration, and DNS management across 150+ TLDs on multiple blockchains.

**Developer Portal:** https://docs.unstoppabledomains.com  
**API Reference:** https://docs.unstoppabledomains.com/apis/overview  
**Website:** https://unstoppabledomains.com

## APIs

- **Resolution API** - Resolve Web3 domain names to crypto addresses, reverse lookup, batch queries, RPC proxy for Ethereum and Polygon
- **Partner API v3** - Domain distribution and management, custody wallets, blockchain operations for Web3 NFT domains
- **Reseller API** - Traditional DNS and Web3 domain registration and management for resellers
- **User API** - Account-level domain search, purchase, DNS management, marketplace, and cart operations

## Authentication

All APIs use Bearer token authentication. API keys are obtained from the [Partner Dashboard](https://dashboard.auth.unstoppabledomains.com). Keys are environment-scoped.

## Pricing

Web3 NFT domains carry a one-time registration fee with no renewals. Pricing ranges from $2 (budget TLDs) to $2,000 (premium short .crypto or .x domains). API access is free; costs arise from domain transactions.
